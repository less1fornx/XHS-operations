# 小红书运营规则基线

本文是本项目的保守业务规则，不代表小红书对“每天 5 条私信、3 条评论”提供安全承诺。平台规则会变化，最终以站内通知和官方公示为准。

## 依据

- [小红书社区公约 2.0](https://pgy.xiaohongshu.com/help/detail?id=1eda0a065dd894063c2e029a49e8f6a1&userType=4)：强调真实分享、友好互动、有序经营，反对持续发送不受欢迎内容、私信骚扰、伪装素人和滥发营销内容。
- [关于不正当商业竞争行为的治理公告](https://pgy.xiaohongshu.com/help/detail?id=8c0b127f03a949d71f1f218a55e7d7f6&userType=4)：将商业撬客列为治理对象，包括在他人相关内容下截流意向用户、私信竞品潜在用户招揽。
- [内容审核规范](https://pgy.xiaohongshu.com/help/detail?id=6495c527d1eedeeb48fb18b1f875650e&userType=4)：关注导流、虚假或夸大宣传、盗图营销、低俗内容、诱导互动和破坏平台秩序。
- [导购笔记与私信豁免说明](https://fe.xiaohongshu.com/dittossr/vincent/8c2fdc33dbff4c0d80eea10cebbc0ecb?fullscreen=true&naviHidden=yes)：说明商业私信豁免属于特定 KOS/投流场景，不能推导为个人号自然运营的通用许可。

## 当前最终判断

### 允许进入工作流

- 手工录入公开店铺和公开内容，不自动登录、不绕过验证、不批量抓取。
- Agent 只提取证据、评分、生成建议；人工决定路线和最终文本。
- AI 只作为辅助，不伪造真人经历、身份或合作关系；涉及公开发布的 AI 辅助内容，按平台要求保留透明标识和人工审核。
- 评论只能围绕当前内容进行具体、友善、非销售性的交流。
- 有具体店铺与内容证据的陌生 B2B DM 可以进入起草流程，但必须标记为陌生触达、经过人工审核，并由人工在官方页面发送；这不代表平台保证安全或合规。
- DM 必须记录联系依据备注；只有选择类型而没有事实备注不能进入流程。
- 在有证据依据的陌生 B2B DM、已有真实交流、对方主动咨询或明确同意商务联系的 DM 中，可以说明“一件起订”等真实供货条件；这不是站外导流豁免，仍需人工审核，且不得搭配联系方式、二维码、网址或强迫成交话术。
- 每个目标每天最多一次新触达，DM 和评论互斥。
- 每日 5 个 DM、3 个评论是本项目的内部保守上限，不是平台安全线。
- 同一天不允许发送完全相同的文案；评论必须引用当前内容中的具体事实，避免模板化批量互动。

### 默认拦截

- 没有具体店铺/内容证据、没有人工审核、内容高度模板化，或试图自动/批量发送的陌生商业 DM。
- 评论中出现供货、批发、拿货、进货、报价、下单、招商、加盟、货源、合作或“一件起订”等销售招揽表达。
- 微信、二维码、手机号、邮箱、网址、外链、第三方平台名称或“看主页”等站外导流表达。
- 夸大、绝对化、无法由证据支持的“最高级”“第一”“保证”“零风险”等表述。
- 冒充官方、冒充普通用户、虚构客户身份、伪造合作关系或使用未经授权的图片、视频、肖像和品牌标识。
- 不收集、不传播与合作判断无关的个人信息；公开页面中的电话、住址、行程、身份资料不进入线索库。
- 贬低竞品、散布未经证实的负面信息、诱导点赞关注、互赞互评、刷屏和模板化重复内容。
- 对方明确拒绝、拉黑、举报、要求停止联系，或 DM 已读无回复且人工确认后再次触达。

### 账号安全动作

- 出现验证码、警告、风控、禁言、功能受限、私信受限、评论受限、账号异常、违规通知、降权、限流、举报或封禁提示：立即冻结新触达队列。
- 冻结后不自动重试、不换账号、不轮换账号、不修改话术规避检测。
- 解冻必须由人工确认平台状态已恢复，并留下处理记录。
- 失败、限制和人工修改都要进入审计日志，便于复盘。

## 仍需人工判断的边界

平台没有公开一个可保证不受限的统一私信数量阈值，因此系统不能把“5 条”包装成合规证明。即使数量未超限，若目标选择、内容相似度、商业意图或互动方式被判断为骚扰或商业撬客，仍可能产生风险。

本项目第一版的正确学习目标是：让 Agent 学会“证据约束、风险识别、人工停点和可追溯”，而不是寻找平台检测阈值。
