# Agent学习路径

这个项目按 Agent 应用的真实设计链路拆分学习。Phase 0 先用无模型实验理解编排，再进入应用开发：

1. 先学领域建模：店铺、证据、任务、风险事件和审计日志。
2. 再学工作流编排：把 Agent 拆成多个有输入输出的节点。
3. 再学结构化输出：模型只负责判断和起草，不能直接改变业务状态。
4. 再学 Human-in-the-loop：人工审核是明确的状态节点，不是页面上的装饰按钮。
5. 再学 Policy Gate：所有高风险动作在服务端统一拦截。
6. 再学评估：用人工修改率、证据引用准确率、风险拦截率和回复率评价 Agent。
7. 最后再学模型替换：同一业务工作流接入云端模型或本地 Ollama。

第一版先用假数据和人工录入，把状态机跑通，再接入真实模型。这样每个 Agent 决策都能被观察和复盘。
